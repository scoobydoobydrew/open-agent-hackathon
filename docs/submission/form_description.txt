Verified Knockout Agent: gene knockouts that provably force apoptosis in radiation-resistant tumour cells, with explanations that are checked.

Problem and users: research teams must choose which gene knockouts to test. Asked directly, an LLM proposed a wrong knockout set 91% of the time and invented a solution for a case where none exists (8 scenarios, exhaustive ground truth).

How it works: an LLM proposes knockouts; an exact solver (Z3 + attractor analysis of a published 35-gene bladder-tumour model) proves or refutes each one and returns a counterexample; a complete counterexample-guided search finds every minimal set or proves none exists (34x fewer solver calls than brute force); each explanation is cut into proof steps re-checked against the model's rules.

Sponsors: Zetaris is the data layer (network rules, scenarios and drug evidence as SQL tables; the LLM writes its own validated read-only SQL). Meterless Nightshift is the primary AI provider: every request goes through it to NVIDIA Nemotron 3.5 Lightning 30B (nvidia/nemotron-3.5-lightning-30b-a3b), and the UI and logs show the model that handled each request. Meterless H-MEM (official engine, unmodified) is the agent's memory: store, ranked recall into every prompt, feedback, audit ledger; tests/test_hmem.py passes, conformance 13/13.

Runs from a clean clone: SAMPLE_MODE=true needs no account; Docker image; POST /run; 102 tests; JSONL evidence logs in logs/.

Limits: in-silico hypotheses on one published model, not medical advice.

Pre-existing: the published Remy et al. 2015 network, the official H-MEM reference (Apache-2.0), open-source libraries. All other code was written in the build window with Claude Code.
